# 信号跑道 v0.4 无限模式内容设计与制作计划

2026-10-01，用户批准并要求执行本方案，制作人与主美已完成无限自动跑、12片段随机拼接、计分/最高纪录、动态场景、回收/坐标重定位及同版本独立验收。当前源工程v0.4.0，9项任务分别验收。实际参数修订、证据和体验范围见“信号跑道 v0.4 工程实现与验收记录”；原预算和日期为计划基线保留。

制作团队为制作人与主美两人。交付一个完整无限模式、12个基础地形片段、随机种子、计分、本机最高分、正式表现与同版本检查，交付Godot源工程，不打包。

## 核心体验与操作

自动奔跑 → 判断前方地形 → 跳跃或蹬墙 → 选择是否接入中继 → 继续前进并得分 → 失败结算 → 再次挑战。

无限模式自动向右奔跑，玩家专注起跳、跳跃高度、蹬墙与路线选择；保留短按低跳、长按高跳。蹬墙短暂反向弹出后恢复向右奔跑，不用强制水平位移覆盖墙跳。Esc暂停，R重开。原首关与断线中继站继续手动移动；无限模式是独立入口，不把旧计时挑战改成自动奔跑。

## 模式规则

| 项目 | 批准的初版规则 |
| --- | --- |
| 终点 | 无终点，持续向前生成地图 |
| 开始 | 确认后自动奔跑，保留起步缓冲 |
| 失败 | 尖刺、坠落或被崩塌吞没，结束本轮；失败优先奖励，多候选只结算一次 |
| 中继 | 身体接触，每个稳定ID每轮一次；延迟追赶0.9秒并提供100分；角色与计时继续 |
| 暂停 | 冻结角色、计时、追赶、生成及表现；延迟不消耗 |
| R及同图重试 | 相同种子从起点开始，清理本轮所有状态 |
| 换图挑战 | 生成新种子并开始另一张地图 |
| 结算 | 总分、最远距离、中继数、用时、失败原因、地图种子与最高分 |

本版沿用现有死亡规则。金币、翻转得分、连击、动物搭乘、载具、成长、任务、商店、联网排行及多主题地图暂不加入。

## 随机地图与片段库

采用经过验证的地形片段加规则随机拼接。片段内部明确动作与落点，生成器选择片段、衔接、难度与奖励位置。首批12片段如下。

| 类型 | 数量 | 用途 |
| --- | --- | --- |
| 安全过渡段 | 2 | 起步、调整节奏及连接 |
| 单项障碍段 | 3 | 坑洞、尖刺、简单高差 |
| 连续跳跃段 | 3 | 不同起跳与落地节奏 |
| 中继分支段 | 2 | 稳路通过，或上路接入奖励 |
| 蹬墙组合段 | 2 | 复用墙面动作，形成较高难度 |

入口与出口采用统一接口，初版统一地面高度衔接，片段内部允许高差。接缝保留安全落脚空间；每段至少有一条实际验证的通路，中继分支另测。开局先安全与简单段，再加入复杂组合。相同片段不连续出现，高难段之间安排调整空间。危险提前进入视野，不能在角色脚下生成。候选无法满足连接条件时使用经过验证的安全过渡段兜底。

每个片段配置类型、稳定模板ID、入口/出口位置及可接受运动状态、碰撞/危险/节点数据、难度与选择权重；具体长度、接缝安全范围及可达界限在A/B测量后冻结，不从示意格数推导。地图设计模块展示片段池与选择关系，不代表一张已完成的固定地图。

前方预生成数个屏幕，后方已经被崩塌覆盖且不会再影响玩家的片段回收。回收清理碰撞、节点、事件和表现，不能只隐藏图像。累计距离独立于局部坐标；长距离统一调整角色、镜头、地形、节点和前沿位置，计分与种子序列不变。具体缓存数量与坐标阈值在D冻结。

同一构建版本、同一种子产生相同地形与节点序列；地形随机与装饰随机分开。改变装饰、帧率或预生成时机不能改变地形前缀。结算显示种子，便于同图重试和报告缺陷。

## 计分与记录

总分＝距离分＋中继分。距离取起点以来最远前进值，每10个世界单位得1分；中继每次有效接入100分，时间只显示、不直接得分。距离12,000、中继3个时为1,200＋300＝1,500分。回退再前进不重复计分，同一节点不重复得分。

无限模式最高分独立保存到本机，退出后保留；原固定关的会话最佳规则保持。保存格式有版本，读取缺失或损坏文件应有明确默认处理，不污染固定关统计。同种子适合直接比较，不同随机种子仅用于个人最高分挑战；初版用统一奖励间隔和地形配比限制差异，不宣称联网竞技公平。

## 追赶压力与难度

当前v0.3角色速度280、追赶270；长期顺畅奔跑会拉开距离，中继又增加余量。无限模式需单独设计压力曲线，固定关参数保持。

| 参数 | 初始候选与验证要求 |
| --- | --- |
| 自动奔跑速度 | 280，先复用现有动作参数 |
| 初始追赶速度 | 270 |
| 追赶增长 | 每30秒提高4，初测上限282 |
| 起步缓冲 | 2秒；初始后方距离先复用640，再按压力证据判断 |
| 中继奖励 | 0.9秒延迟及100分 |
| 中继间隔 | 约20–30秒路程，受生成与可达约束控制 |

以上均为原型比较值，不是已验证数值。难度时间使用有效游戏时间，暂停冻结，接入延迟时仍累计；奖励间隔依据生成路程预算，不能受停留或装饰随机影响。先起步宽落点及单项障碍，再连续跳跃与分支，最后加入蹬墙和较高组合比例；速度与密度都有上限。

错过中继后仍能继续尝试；扣除绕路成本后奖励有正收益；后期正确操作并接入中继应有维持余量的可能，不能到某时刻无论怎样操作都必死。用最不利允许奖励间隔和实测动作耗时核对长期收支，不能只比较0.9秒的理论收益。难度不靠随机不可达路线提高。

## 验证与交付标准

每个片段与允许的连接组合验证通行，包括墙跳出口、中继路线和片段之间的运动状态。至少100种子做结构检查，选择代表种子用普通动作输入跑长路线；结构检查不能替代动作可达性。相同种子前缀、不同预生成时机与装饰随机隔离检查。

回退、重复节点、暂停、失败同帧、R同图与换图均不误加分；纪录保存/读取/缺失/损坏处理正确，固定关成绩不串写。30分钟连续运行检查活跃片段/碰撞/表现数量及内存趋势，并测试坐标调整，明确长局fixture与正常路线证据的区别。

比较接入、错过与动作损失轨迹，记录不同难度阶段的余量变化与中继净收益。主美检查同版本真实入口/键盘流程、画面、接缝及报告复现，我审核并收口。修复发生在独立检查后时，生成新清单并补充具体风险的同版本确认。

交付一个无限模式、12片段、随机种子、计分、本机最高分、正式表现、源清单、docs/run-v0.4.md及reports/v0.4报告；保留原首关、中继站及控制测试房。自动检查证明规则与路线，重复游玩的吸引力、主观压力与听感由实际试玩另记，未组织时不填已通过。
