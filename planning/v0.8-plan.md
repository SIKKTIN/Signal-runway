# 信号跑道 v0.8 主动技能与路线收益制作计划

2026-10-01，制作人整理。用户批准以信号冲刺、行动资源和路线收益选择扩展玩法，先做技能及三段手工玩法原型，再确定无限生成的组合范围。本计划供制作人与主美双人执行，登记时尚未开工，当前正式交付为v0.7。不打包。

## 目标与玩法假设

用户反馈当前跑起来无聊。制作人的设计假设是：现有自动奔跑与跳跃主要要求按地形完成动作，中继承担计分和延迟作用，玩家主动改变局面的选择不足。v0.8让中继同时成为行动资源，让玩家选择现在冲刺抢线、连续接力，或保留次数救场。此判断需要实际试玩验证，自动无伤通关不能证明趣味性。

核心循环：观察入口与落点 → 判断冲刺储备 → 跳跃或冲刺进入挑战 → 接入节点补充资源 → 衔接下一落点并完成原有连段 → 留一次应对失误或追赶压力 → 继续奔跑、恢复站选择或结算。

## 信号冲刺与资源规则

| 项目 | 初版制作基线 | 调整与验证 |
| --- | --- | --- |
| 操作 | Shift触发短距离向前冲刺，地面和空中可用；跳跃按键保持 | 按下沿触发，按住不连发；暂停、菜单、终局不消耗 |
| 次数 | 开局1次，最多2次，充能进度初始0 | HUD同时显示当前次数和两节点充能进度 |
| 补充 | 每首次接入2个唯一中继节点恢复1次；两节点进度完成后清零 | 储备已满时不累积隐藏额外储备；分数及节点接入照常结算 |
| 时长与速度 | 原型起点为0.20秒、水平速度800单位每秒，约160单位位移 | 这是待M1调整的初值；落点必须可控，不作为已验证参数 |
| 垂直行为 | 保留重力和垂直速度，不自动吸附、不自动寻找落点 | 空中冲刺用于改变水平可达范围，跳跃仍决定高度 |
| 结束 | 返回当时实际目标跑速，原有无伤距离加速和伤害降速继续 | 不把冲刺速度写成永久跑速，不给予额外无敌或追赶延迟 |
| 受伤与终局 | 尖刺照常伤害，受伤取消本次冲刺并执行原降速；已消耗次数不返还 | 生命归零、被吞没或不可恢复的终局优先，不能终局冲刺复活 |
| 冲刺期间输入 | 不重复触发冲刺；正常跳跃是否允许由M1手感确定并记录最终规则 | 初版允许符合原着地规则的跳跃，不追加二段跳 |
| 重试与恢复 | 同图重试回到1次与0进度；单次扣血/安全点恢复保留剩余资源 | 已接入节点身份保持，回跑、恢复、坐标重定位不重复充能 |

满储备下继续接入仍获得原有分数；不增加独立“冲刺得分”或额外延迟。失败种子定位试玩从公开的初始资源开始，原局资源状态另作可选调试快照并明显标注，不能冒称原局完整动作重放。

## 三段手工玩法原型

| 原型 | 玩家选择 | 关卡制作条件 | 要观察的体验 |
| --- | --- | --- | --- |
| 冲刺捷径 | 消耗一次抢上远处高路，或沿稳定主路跳跃 | 提前显示技能入口与中继收益；主路零冲刺可通行 | 玩家能否识别花一次能换来什么，是否愿意主动选高路 |
| 空中接力 | 跳起接入节点，再冲刺衔接下一落点 | 对应原有三节点连段，节点落在实际行动轨迹上 | 接入、补充、冲刺能否连贯，是否需要明确的操作与充能反馈 |
| 紧急脱险 | 跳跃失误或崩塌接近时使用储备，或继续依赖正常跳跃 | 设置可救回且不自动救回的情境；终局条件保持 | 是否能理解救场时机，是否愿意留次数，是否仍有追赶压力 |

三段通过同一真实Player/冲刺/节点组件运行，提供反复试玩和明确起点条件。灰盒可以先用现有美术。先确定手感与收益，再扩充随机组合，M1发现输入、距离或充能节奏问题时先修原型。

## 无限生成与风险收益

技能路线与v0.7坡地、高台、断桥和跨段高路组合；复用节点基础100分、原挑战出口连段200分及原站点积分，不默认额外发奖。高路通过节点密度、连贯轨迹和接入后的资源补充体现收益，重排后仍遵守每片段首次接入0.9秒延迟上限。

生成分成固定布局和运行提示两部分。种子与冻结配置决定地形、节点、技能入口及所需冲刺次数，不能按实时血量或储备重抽已生成地图。进入片段时读取当前储备显示是否足够，并验证可选路线资源预算；缺资源时有清楚提示和稳定替代路线，不通过隐藏地形制造陷阱。

前期单次技能、宽落点、清楚收益；中期技能与坡地/高台组合；后期两次衔接，穿插缓和地形。限制连续技能挑战数量，恢复站间隔与原连续挑战上限保持。稳定路线必须在零冲刺、280/330/380和受伤降速下可达，技能路线分别验证需求满足时的真实轨迹。默认配置、可调范围与阶段密度在M1后冻结。

## 功能系统

| 系统 | 制作内容 | 接口与关键限制 |
| --- | --- | --- |
| 玩家冲刺 | 触发、消耗、水平运动、结束/受伤取消、暂停和重试 | 实际碰撞步进，不瞬移穿墙；状态变化事件供表现读取 |
| 中继充能 | 唯一节点充能、两节点进度、容量上限与资源HUD | 复用全局节点身份；分数、连段、延迟结算各保持独立 |
| 三段原型 | 捷径、接力、脱险的可操作灰盒与试玩入口 | 使用真实游戏组件，起点/速度/压力的测试注入明确 |
| 技能路线生成 | 技能入口、需求次数、预期节点收益、稳定主路与阶段节奏 | 同种子同配置同布局，运行储备只影响提示和可行性判断 |
| 工具试玩 | 显示技能需求/收益，原型入口、资源条件与轨迹辅助 | 调试注入可见，隔离成绩，保留连接试玩/晚失败窗口/F8 |
| 视听反馈 | 起手与尾迹、耗尽/充能/补满反馈、入口标识与HUD | 颜色之外有形状/文字；白顶、角色、落点和现有HUD可读 |
| 兼容与记录 | 新版配置/规则及独立v08成绩、资源调试快照 | 旧生成2至5/规则与旧成绩保留；失败定位不是输入录像 |
| 验证与体验记录 | 真物理、资源不刷、生成预算、恢复/生命周期及独立操作 | 明确自动输入/定点/加速方法，玩法假设与已证实功能分开 |

实现拟使用生成revision6、规则revision8与user://signal_runway_endless_v08.json。旧配置显式升级；不会因新版默认而悄悄改变旧地图。最终字段结构由M1接口冻结记录，编辑器与正式模式读取同一配置。升降、塌落平台作为后续候选，是否加入由技能原型的玩法需要决定，不列入本版必交范围。
