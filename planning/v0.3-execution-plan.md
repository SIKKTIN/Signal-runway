## 玩家循环与信号中继规则

选择关卡与模式 → 首次动作开始 → 建立安全余量 → 观察分支 → 选择稳妥路线或中继路线 → 接入中继争取喘息 → 分支汇合继续前进 → 成功或失败 → 快速重开并调整选择。

| 项目 | 批准的规则 |
| --- | --- |
| 激活方式 | 玩家身体接触节点，不增加按键 |
| 数量 | 新关卡2个可选节点，每节点每轮只能激活一次 |
| 初始收益 | 崩塌前沿暂停推进0.9秒，作为首轮调参值 |
| 玩家与计时 | 玩家继续正常跑跳，本轮用时继续累计 |
| 前沿 | 保持当前位置；延迟结束恢复固定推进，不后退、不传送、不按距离暗中变速 |
| 通关条件 | 不必收齐中继，存活抵达终点即可 |
| 计时模式 | 可记录激活数量，不产生追赶延迟 |
| 暂停和结果 | 暂停冻结延迟；失败或成功停止本轮；不能靠结算后接触继续激活 |
| 重开 | 重置节点、延迟、角色、镜头、计时和本轮激活统计 |

270×0.9=243单位是少推进的理论量。分支的实际收益还需扣除绕路及动作耗时：比较同一入口状态、同一汇合出口上的用时与安全距离。取得中继的额外耗时应明显小于0.9秒；若收益为负，先调整分支路径，再讨论延迟值。

边界补充：不同节点各提供一次完整延迟；极端情况下同帧接触两个不同节点可累计，两个节点最多贡献1.8秒，不因持续重叠刷新。激活发生在起步缓冲内时，缓冲仍按原规则消耗，中继延迟在其后消耗；有效delta分段处理，不重复消耗同一时间。已出现的死亡/吞没不能被中继撤销，失败优先于终点或奖励。具体同帧采集与判定顺序在A原型中冻结并记录。

计时模式一次自动死亡恢复仍属于同一轮，已激活节点不重复奖励/计数；R或再次挑战才创建新一轮。节点按稳定ID去重。最佳成绩改为按关卡与模式区分；原首关会话成绩映射到原首关，不与新关卡混写，仍不做长期存档。

## 新关卡 断线中继站

新增一条约45–65秒的完整关卡。横向推进为主，两处局部分层分支在短段挑战后汇合。原首关继续保留。

| 段落 | 预计时长 | 内容与体验 |
| --- | --- | --- |
| 接入区 | 6–8秒 | 宽平台、低强度障碍，建立跑跳节奏，提前看见第一处中继 |
| 第一处分流 | 10–12秒 | 下层宽落点常规路线；上层两次高差跳跃取得中继，随后汇合 |
| 连续传输区 | 8–10秒 | 短跳、长跳和落地衔接，提供连续前进的顺畅段 |
| 第二处分流 | 12–16秒 | 稳妥路线落点更宽；中继路线使用一次蹬墙与空中落点组合 |
| 输出区 | 8–10秒 | 收束动作组合，终点提前可见，完成最后冲刺 |

五段预算合计44–56秒，整关45–65秒为含实际选择与操作差异的目标范围，不能当作已实测成绩。地图是段落和连接示意，世界尺寸以灰盒动作能力测试决定，不从参考截图或示意格数反推跳跃参数。

稳妥路线落点更宽、动作要求低，能够独立通关。中继路线需要更准确的起跳和衔接，收益位置及出口提前可见。选择后仍持续向前，不加入取完奖励再大幅回头的流程。两处分支的四种组合都应可达：稳/稳、中继/稳、稳/中继、中继/中继。

分别记录段落进入、离开、最低余量及分支入口/汇合点用时。采用普通方向与跳跃输入完成路线，不用传送、无敌或冻结追赶证明可达。定点fixture仅用于碰撞、状态或排版检查。

## 追赶节奏与调参

预期节奏：建立余量 → 选择路线 → 挑战消耗余量 → 中继提供喘息 → 连续前进 → 第二次选择 → 终点冲刺。

先沿用270/640/2秒和当前玩家动作，通过布局测试压力变化。稳妥路线须能完成，中继提供可感知的改善，错过节点还能继续尝试，后半关仍有追赶压力。现有v0.2顺畅输入路线终点余量约1369.62单位；这只证明可达，不证明真人紧张感充分。

先完成第一处分支与节点收益实验，通过后扩成整关。A和C记录实际耗时与风险收益；若需要调参，记录构建、改动原因、前后路线差异及兼容影响，再更新有效参数。

## 验证与版本判断

技术检查：两个节点每轮各一次；不同节点累计与同帧/起步缓冲边界；延迟结束无跳变；暂停冻结；连续重开无残留；中继不能撤销已失败；原首关及原计时恢复兼容；成绩按关卡/模式隔离。

路线检查：四种组合普通输入通关；稳妥路线无必选节点；同入口条件下比较绕路成本与汇合收益；记录每段最低余量、危险/落点误判和短停影响。必要的失败复现单独记录，不以测试脚本或截图声称趣味性成立。

体验观察：玩家能否提前理解分支，能否说明中继收益，是否会在失败后调整路线/动作，节点是否值得拿，后半关是否还有压力。先记录团队实际体验，外部试玩须注明参与者、构建和真实观察；未组织时明确未覆盖，不填成已通过。

最终交付依据为同版本工程与证据。趣味性仍需实际使用者反馈；本设计的目标时长、奖励值与预计难度是待验证假设。
