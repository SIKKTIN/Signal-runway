# 信号跑道 v0.7 连续地形与路线组合制作计划

2026-10-01，制作人与主美两人完成用户批准的v0.7源工程。真实多边形坡面、有界跨段地面、四类空间结构、跨2至3段高路、坡面安全恢复、旧配置2/3/4及规则7独立记录、连接试玩/失败种子局部复盘和正式空间表现已实现。A至G七任务按证据验收；实际规则、独立操作、继承证据与局限见“信号跑道 v0.7 工程实现与验收记录”。原18至26/6至10小时估算与建议日期保留，不打包。

## 目标与核心循环

玩家奔跑时观察地面走势、选择起跳点和落点，决定进入高路或沿主路通行。高路可跨片段延续，并提供分岔和回到主路的出口；实际奖励节点放在对应路线。失误继续承担扣血、降速与崩塌压力，在安全地面恢复并选择恢复站，进入下一组空间挑战。

本版验证地图空间与跳跃组合是否丰富、连接是否自然、最高速度下路线是否可读。自动输入用于验证规则和动作可达；实际趣味性与主观平衡结合用户试玩判断，不冒称真人测试。

## 功能系统

| 系统 | 制作内容与规则 |
| --- | --- |
| 连续地形 | 上坡、下坡和跨段高度衔接；坡面使用实际多边形碰撞，不能用贴图假坡。地面高度有界，不无限向上或向下漂移 |
| 路线组合 | 高路跨2至3片段连续，入口、延续、汇回可辨；主路可通行，一次挑战仍为原三个节点及出口，跨段装饰不自行增加奖励 |
| 空间结构库 | 坡地连跳、高台跨越、断桥接续、下沉回升四类，每类由高度、间距、起止地面和种子产生变体 |
| 难度与连接 | 距离阶段增加挑战结构权重，连续挑战上限、缓和段和恢复站保持；斜坡角度、必经落点、高路接缝和受伤降速受约束，非法候选有有限安全兜底及解释 |
| 地图编辑器 | 预览最终坡面、地形高度曲线、主高路连接、起跳/落地区域；选连接处隔离试玩，失败种子与配置可保存并加载回放 |
| 场景表现 | 高架、坡地、下沉空间使用实际地形的支撑、层次和标识，保留滚动信号与工业风；不遮白色可站立边沿、不绘制假碰撞 |
| 成绩兼容 | 四类计分保持，v0.7新记录独立且带规则/生成版本和配置指纹，旧成绩不改；旧生成2/3/4必须按原规则读取，显式升级5 |
| 验证与回归 | 结构确定性和连接检查、实际Player三速度及受伤降速、安全恢复/重定位、工具隔离、旧模式回归、主美独立多种子报告 |

## 继承范围与参数初值

三点生命、1.2秒无敌、280至380无伤距离加速、伤害降速、实际安全落脚恢复、崩塌压力和每中继片段首次接入0.9秒延迟保持。连段仍依次接入三个节点并出段，基础分保留；恢复站补1生命或积分200互斥，终局优先。固定关与计时关保持旧规则。

生成配置revision5显式增加有界地面高度变化、跨段高路长度、四种空间结构权重。地面初始448，主入口/出口保持在384至512的初始包络；单段净变化最多64，坡度不超过约0.35，阶差32至64、平台间距64至96，缓和连接与恢复站附近限制组合。高度范围及连接规则最终依实际轨迹验证冻结，编辑器检查不能冒称实时模拟。

跨段高路不把普通落地算中断，不重复延迟或领分。恢复点必须来自真实稳定落脚，含坡面高度；无法恢复、生命归零或崩塌追上结束本局。试跑从连接前安全位置起跑，注明位置/距离注入，成绩隔离；失败回放是相同种子/冻结配置和失败距离定位，非逐帧输入录像。
