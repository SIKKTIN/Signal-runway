# 信号跑道 v0.7 运行与空间生成工具

Godot4.7.2打开project.godot，F5进入无限挑战；工具打开scenes/tools/generation_editor.tscn按F6。本版交付源工程，不打包。无限自动奔跑，Space/W/上箭头跳跃，R同图重试，Esc暂停；固定关和计时模式保留。

## 连续空间与路线

生成revision5加入坡地连跳、高台跨越、断桥接续、下沉回升四结构，按种子、阶段、空间权重和实际参数选择。入口/出口地面跨片段一致，默认384至512，局部下沉最深544；净变化最多64。真实多边形坡面与预览共用几何，贴地和坡面恒速只用于新版无限模式。缓和段、连续挑战上限和稀疏恢复站保持。

高路可延续2至3片段，金色标记提示入口、延续与前方汇回，下路保持实际可通行。断桥主路使用平台接续，错过落脚需要承担原掉坑后果。坡面的可站立顶沿为实际碰撞边沿；暗支撑、侧板、背景灯和引导线是装饰。

一次连段仍在原挑战片段内，顺序接入三个节点，出段额外200分，节点基础100分。跨段高路延续不另增节点、连段分、声音或追赶延迟。同一中继片段最多首次接入延迟0.9秒。中断保留基础分，回跑/恢复不刷奖励。恢复站每16至24片段，路线选择补1生命上限3或积分200，互斥一次且终局优先。

三点生命、1.2秒无敌、无伤距离加速280至380、受伤降速与重新积累保持。安全点来自实际稳定着地，含坡面高度；掉坑扣血后尝试回最近仍存在的安全位置，崩塌、生命耗尽或无安全点结束。镜头跟随纵向变化，全球奖励/安全点身份随坐标重定位保持。

## 成绩与复盘

四类得分仍为最远距离、唯一节点、完成连段和站点积分。v0.7成绩独立signal_runway_endless_v07.json，规则7/生成版本/配置指纹和种子保存；v06/v05及更早文件保留。

正式无限失败会尝试保存最近失败种子到user://map_editor_failure_v07.json，含种子、冻结配置、指纹、失败位置和原因。工具的“保存本次失败种子”保存当前工具试玩失败；“加载最近失败种子”恢复原配置并显示失败附近20片段。随后可用“失败连接前试玩”定位复盘。它复现地图并提供调试起点，不记录或回放逐帧操作；复盘不会继承原血量/速度/追赶位置。

## 编辑器

空间控件包括净高差、地面高度范围、高路片段长度和四结构权重；坡地安全候选权重至少1。节奏与奖励仍用原控件；旧模板字段在v5锁定并说明兼容用途。旧配置2保持几何锁定、3保持立体原规则、4保持段落原规则，只有显式“升级v5草稿”才切换新空间；保存/应用仍校验、确认、备份，当前局冻结配置。

画布显示真实多边形、地面高度曲线、主路/高路连接、起跳及落脚候选区。详情显示实际全局片段编号、入口/出口高度、前接/后接高路、结构参数和候选原因；结构检查不等于所有输入都可通行或实时物理模拟。

“选段试玩”从该段实际地面安全入口开始；“连接试玩”从该连接前192单位开始。两者公开注入位置与距离，三行可见说明标注成绩隔离，角色仍从初始三生命和新局追赶状态开始。280/330/380或自然加速可选，F9受伤、F10掉坑，F8返回并清理本次隔离记录。远距离定位只重建生成前缀状态，活动碰撞保持少量，预览窗口保留实际片段编号。

改变参数后重新生成；点击“随机种子”回到从0开始的预览。加载失败种子后，预览只显示该失败附近；定位需要重建相同种子的前缀，极远距离会耗时。命名方案、默认比较、应用确认和备份沿用原工具。

## 验收范围

新版无限镜头随实际地面高度移动，保持水平平滑跟随，并把角色脚底及近处落脚沿留在生命栏上方。固定模式与旧生成配置保留原镜头。

reports/v0.7保存生成、真实轨迹、运行/记录、编辑器、主美表现/独立检查和最终清单。自动输入、定点/伤害/终局fixture、GPU或headless、正常墙钟或fixed60游戏时间均按方法说明读取。600游戏秒流式检查不代表十分钟墙钟真人游玩；主观趣味性和其他设备仍需实际试玩。
