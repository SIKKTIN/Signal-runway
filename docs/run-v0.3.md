# 信号跑道 v0.3 运行说明

Godot4.7.2 stable打开project.godot，F5运行。开始界面默认选择断线中继站，也可选择原首关；追赶挑战和原计时模式均可进入所选关卡。控制测试房继续独立使用原计时规则。交付源工程，不打包。

操作：A/D或左右方向移动，Space/W/上箭头跳跃或蹬墙，短按低跳、长按高跳；Esc暂停/继续，R重新挑战，Enter开始/结果后再玩。开始界面下拉框选择关卡，原首关的操作与碰撞规则保持。

## 中继站

五段路线：接入区、第一处分流、连续传输、第二处分流、输出区。两处分支都可选下层稳路或上层中继路线，之后向前汇合。两个金色节点可选，身体接触即接入，不增加按键。无需收齐即可抵达终点。

追赶中，每节点每轮一次提供0.9秒延迟：前沿暂时停止平移，波形继续滚动；玩家和计时继续。不同节点可累计，起步缓冲先于中继延迟消耗。延迟结束正常推进，前沿不后退。已经发生的死亡/吞没不能被奖励撤销，同帧失败优先于终点或节点。

原计时模式记录节点数量，不产生追赶效果；死亡自动回起点并保留本轮节点/统计，已接入节点不能再计数。R/再玩完整重置节点、延迟、角色、镜头和本轮统计。

暂停冻结所有有效时间、延迟、画面时钟与音效；结果停止本轮。最佳通关成绩按关卡和模式分别保存在本次程序会话中，只有成功更新，退出程序不保留。原首关没有节点，沿用v0.2规则。

原型、路线预算、图形集成、主美独立检查与最终源清单见reports/v0.3。测试环境Windows / Forward+ / D3D12 / RTX4050 Laptop GPU，960×540逻辑画布。自动输入、状态fixture和主观体验的范围分别记录。
