# 信号跑道 v0.2.1

使用 Godot 4.7.2 stable 打开根目录 project.godot，F5 运行。规则及控制见 [v0.2 运行说明](run-v0.2.md)。

本次是进入 v0.3 前的美术动态优化：滚动信号波、流动崩塌覆盖、工业背景视差、信号脉冲与环境微粒。首关与控制测试房共用独立环境组件。动画使用各自可冻结的时钟，暂停和结算保持静止，重开清零。追赶参数仍为速度270、初始距离640、起步缓冲2秒。

关卡碰撞与玩家动作沿用原版；背景分层和滚动波形仅负责表现。波形在真实追赶边界后方运动，边界前方没有致命覆盖。

此次交付源工程，不打包。检查证据与画面在 reports/v0.2.1。
