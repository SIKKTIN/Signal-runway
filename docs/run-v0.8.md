# 信号跑道 v0.8 冲刺与路线收益

Godot4.7.2打开project.godot，F5运行主游戏。无限自动奔跑，Space/W/上箭头跳跃，Shift冲刺，R同图重试，Esc暂停。地图工具scenes/tools/generation_editor.tscn按F6，三段原型scenes/tools/dash_prototypes.tscn也可单独F6。不打包。

## 主动冲刺与行动资源

开局1次、最多2次，地面和空中均可Shift向前冲刺，0.20秒/水平800；保留垂直重力，不自动找落点，没有新增无敌。结束回当前跑速；正常无伤距离加速280至380、受伤降速重积累保持。按住Shift不会连发，冲刺中不能再次启动。

每两个新中继节点补一次，HUD显示两格储备与0/1个节点的充能进度。满储备不积累隐藏次数；已接节点、回跑、恢复、回收重定位不重复充能。受伤取消冲刺但已消耗不返还，安全恢复保留剩余资源，同图重试回1次/0进度，终局不能启动或充能复活。

## 路线选择与收益

新生成6保留四种空间地形、跨段高路及原段落/恢复站节奏，在中继分路窗口加入冲刺捷径、空中接力与紧急脱险。稳定路线零冲刺可走，仍需要正常跳跃；技能入口显示需求和收益，地形由固定种子/配置决定，不按实时资源重抽。

捷径有一处高路冲刺衔接。空中接力总用两次，但可靠接入前两节点可补一次，因此最低入口1次；漏点或错误操作会中断，提示不是自动成功承诺。脱险段的缺口可以正常跳过，也允许短跳失误时主动冲刺救回；前段提供补给节点，最低资源0，不额外给连段奖。资源充足时也可花储备拉开与崩塌的距离。

节点仍基础100分，原有三节点有序连段出段200，站点补1生命或积分200互斥。每片段仅首次接入延迟0.9秒，冲刺不额外延迟。成绩仍最高距离、唯一节点、完成连段、站点积分四类相加；新规则8/生成6使用独立signal_runway_endless_v08.json。

技能频率档1至少隔一个中继窗口，档2允许相邻中继窗口；原连续挑战上限与缓和/站点间隔保持。权重0关闭技能地形，仍保留冲刺操作。新数值/频率是否更有趣需实际试玩，自动检查仅证明已验证的动作与选择机会。

## 工具与原型

编辑器显示实际地形、入口/落点、金色冲刺衔接、最低资源/总消耗/节点收益。可调技能权重0至3与频率1至2；0.20秒/800按M1冻结，不接受未验证数值。旧生成2至5读取原地图、无冲刺并保持规则7与v07原成绩，只有显式升级6改变草稿；命名方案/应用确认/备份及当局配置冻结保持。

试玩可选择0/1/2次资源公开注入，正常/固定三速度、选段/连接前起跑、F9受伤/F10掉坑/F8返回保持。三行说明记录起跑条件，运行后真实资源以HUD为准；所有工具成绩隔离。远距离只重建同种子前缀状态，失败附近20段仍真实编号，不创建已跳过段落碰撞。

失败文件map_editor_failure_v08.json带冻结配置、指纹、位置原因和资源快照。加载后可选择原charges/progress注入，从失败片段连接前复盘；不恢复动作、生命/速度/前沿，不是逐帧输入录像。旧schema1定位文件兼容，新旧正式文件路径分开。

“三段玩法原型”从编辑器打开，选捷径、接力、脱险及明确资源/固定速度条件，真实Main/Player运行。F8先返回原型选择，再F8返回地图编辑器。

## 验收方法与范围

reports/v0.8保存结构、真实物理、资源与优先级、工具、主美表现、独立检查、流式运行和最终清单。自动输入、显式fixture、headless/GPU、加速游戏时间与正常墙钟均按报告读取，不等同真人趣味性或主观听感。固定关/计时/测试房按旧规则运行，旧历史结果保留。
