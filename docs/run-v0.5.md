# 信号跑道 v0.5 运行与地图工具

使用 Godot 4.7.2 stable 打开 project.godot，F5 运行无限挑战。角色自动向右，Space/W/上箭头跳跃；R 同种子重试，Esc 暂停，结算后可换图。本版本交付源工程，不打包。

## 生存与速度

开局三点生命。尖刺接触扣一点，伤后 1.2 秒无敌并降回基础跑速；无敌不能抵消后方信号崩塌。生命归零或被崩塌追上结束本局。

基础目标速度 280，伤后新增最高距离每 5000 增加 10，最高 380。实际速度受运动加速度、跳跃和墙跳影响。伤后重新积累，后退跑旧路不能重复获得加速或距离分。左下状态栏显示生命、实际与目标跑速以及受伤/无敌状态。

掉坑扣一点后尝试恢复到最近实际站稳的安全落脚点。计时与追赶继续；安全点已被崩塌覆盖或不存在时本局结束。掉坑不能向前传送、重领节点或减少最高距离。暂停冻结生存、追赶与界面动画。

## 高低路线

地图包含阶梯抬升、下沉回升、断层桥接、连续平台链、上下双路线及高处接入回落六种结构。平台高度和间距在已验证的离散档位内变化。高路平台允许从下方穿过并从上方落脚；下路较稳，高路有额外唯一中继节点。深处地面由镜头垂直跟随，首尾连接回统一地面高度。

计分沿用最高距离除以 10 取整，加每个唯一节点 100 分。同一个中继片段首次接入延迟追赶 0.9 秒，高路的额外节点继续加分；延迟总额按片段限制，避免叠加后永远甩掉崩塌。v0.5 最高分独立保存在 user://signal_runway_endless_v05.json，原 signal_runway_endless.json 保留。记录携带规则版本、生成版本、配置指纹与种子。

## 地图编辑器

打开 scenes/tools/generation_editor.tscn，F6 运行。连续地图支持缩放、拖动、选段与单段查看。调节片段权重/开关、阶段和中继间隔，以及高差 32/48/64、平台间距 64/80/96 的最小/最大档位。详情显示实际几何、结构、参数、路线表面、候选与兜底；改参数会重新生成实际几何。

试玩速度可选自然加速、280、330、380。试玩中 F9 注入一次受伤，F10 模拟掉坑，F8 返回。伤害会清除固定速度调试，恢复自然加速。测试快捷键只存在于编辑器试玩；普通游戏使用真实危险触发。

旧 revision2 方案会明确显示“旧配置模式，几何锁定”，保持旧片段顺序。点击“升级v3草稿”才切换新几何；保存方案保留版本，应用工程默认需要确认并保留 .bak。R 继续同一局规则快照，新局/换图加载新默认。编辑器成绩独立，退出清理本次试玩文件。

生成检查表示结构约束满足。发布范围的六种结构有真实角色物理检查，但自定义权重的长期压力仍需试玩；工具显示的绿色安全表面是可作为落脚点的几何，正式恢复点必须实际站稳后才会登记。
