# 地图生成编辑器运行说明

Godot4.7.2 stable打开project.godot，在文件系统打开scenes/tools/generation_editor.tscn，按 **F6运行当前场景**。F5继续运行正式游戏。源工程不打包，编辑器使用与游戏相同的片段库和生成器。

## 调图流程

1. 输入种子和4至120预览段数，点击重新生成；随机种子可比较不同布局。
2. 左侧调整阶段距离、中继最小/最大段距、片段开关和合格候选权重，0.15秒后自动重生成。安全A/B和中继A不能关闭，权重至少1；其余片段可禁用。难度、安全调整、接缝和墙跳预算保持约束，权重再高也不能越过资格限制。
3. 在地图中滚轮缩放、左/中键拖动、点击选段，或用上一段/下一段/单段查看。整体适配显示全序列；长序列缩小时应放大看地形。青色安全段、黄色中继和红色危险，线框显示尖刺判定范围。
4. 查看段边界、阶段与难度、真实库几何、选段原因/候选排除、分布、安全兜底、参数差异和与工程默认相同种子不同的段数。详情区与参数栏可以滚动。
5. “100种子结构检查”检查当前配置的100×200段规则；这不证明新配置的长期压力、动作可达或真人趣味性。
6. 点击当前草稿试玩：正式游戏按该配置和种子自动跑，Space/W/↑跳跃和蹬墙，R同图、换图仍用该草稿。**F8返回编辑器**。试玩纪录单独临时保存，退出清理，正式最高分不写入。

## 保存与应用

输入1至32位字母、数字、中文、下划线或短横线方案名，保存到Godot用户数据目录的map_editor_profiles。下拉选择后加载；同名保存原文件备份为.bak。方案只存生成规则，种子和段数在顶部；指纹识别规范化规则内容，不受JSON字段顺序影响，同种子复现限定相同规则版本与构建。

“恢复内置默认”只修改草稿。加载上次默认备份同样只修改草稿；需点击“应用工程默认…”并在确认框确认才会写入resources/generation/endless_default.json，上一版保留为.bak。应用失败会显示原因并保留原文件；导出只读工程不支持该写入，但仍可保存个人方案和试玩。

应用影响正式游戏新开始/换图的无限局；已经运行的一局和R同图重试保持冻结配置。编辑器试玩始终使用注入的草稿快照。正式默认缺失/损坏时回退内置v0.4规则并提示，不改变个人纪录。

## 第一版范围

可调整片段选择和阶段/中继节奏，查看12片段真实几何；地形自由拖拽绘制和新片段创建留待后续。默认生成序列与v0.4一致，片段长度1280、角色动作/追赶/计分保持。自定义配置需要用实际试玩判断难度和压力，结构检查不提供这类结论。

制作/验证记录见reports/v0.4.1/config-editor.md、independent-review.md及final-acceptance.md；冻结源文件清单version-manifest.json。
