# 信号跑道 v0.6 运行与地图编辑器

Godot 4.7.2 stable 打开 project.godot，F5 运行无限挑战。自动向右奔跑，Space/W/上箭头跳跃，R 同图重试，Esc 暂停。此版本交付源工程，不打包。

## 跑酷段落

地图由缓和、挑战、分路、恢复四类段落编排，段内使用实际参数化几何。距离阶段初值10000与30000，挑战候选权重递增，最多连续两段挑战后调整。开局有安全缓冲，恢复站前后有缓和连接。主路在基础速度可通行，高路用连续平台争取额外收益。

每局三点生命，真实伤害扣一点并降速，无伤新增最高距离使目标速度280至380。1.2秒无敌不能抵消信号崩塌，掉坑尝试回实际站稳的安全点；生命耗尽、被追上或无法恢复时结束。继承规则详见v0.5运行说明。

## 高路连段

经过高路挑战入口后，按顺序接入三个挑战节点，再通过出口完成连段。每个节点基础100分，连段完成额外200分。普通中继节点继续采用原接入规则。同一中继片段首次接入延迟追赶0.9秒，额外节点和连段分不增加延迟。

有效伤害、漏点、落回下路或终局中断当前连段，已经得到的节点分保留。高路正常平台落脚允许继续；回跑或掉坑恢复不能重启同一个挑战。没有选择高路时不会提示连段失败。

## 恢复站

默认每16至24片段生成一次，使用路线作选择，不打开菜单。上方补血路线恢复一点生命，最多三点；下方积分路线获得200分。接入任一路线立即锁定该站，不能领另一份。满血上路显示生命已满，仍可通行，但不给生命或积分。补血不清除加速积累，不延迟追赶。

致命伤害与崩塌优先结束本局，恢复站不能复活。非致命伤同帧先扣血降速，再处理仍有效的补血。回跑、恢复与重复接触不能多领。

## 分数与记录

总分为最高距离除以10取整，加唯一节点基础分、连段完成分和恢复站积分。结算显示四类分数，以及完成连段、补血选择、积分选择次数。v0.6最高分单独使用 user://signal_runway_endless_v06.json；旧v0.5和更早记录保留。新记录带规则版本、生成版本、配置指纹和种子。

## 地图生成编辑器

打开 scenes/tools/generation_editor.tscn，F6。画布显示正式生成器实际几何和段落类别，选段详情显示挑战与恢复站收益、候选和兜底；有序节点与互斥站点直接标在地图上。

可调高度/间距、阶段边界、挑战基础权重和连续上限、恢复站间隔、额外奖励，以及合格片段权重。恢复站使用固定32高差/80间距的宽平台，保证选择窗口；其它高路按草稿几何档位生成。v4暂不选用的旧尖刺/墙跳结构控件显示锁定，旧v2/v3仍保留这些结构。参数有合法范围；结构检查不代表自定义方案已经经过实际动作和长期压力验证。

旧revision2显示几何锁定，旧revision3保留立体几何且节奏锁定。点击升级v4草稿才增加新编排；保存方案保留版本，应用工程默认需确认并备份。当前局冻结配置，R保持种子和配置，普通新局读取工程默认。

当前草稿试玩从正常开局；选段试玩在选中片段的安全入口定点起跑，明确注入距离并使用隔离成绩。三速度和自然加速均可选，F9受伤、F10掉坑、F8返回。工具成绩不写正式最高分，退出清理本次临时记录。

## 验证范围

制作证据在 reports/v0.6。自动跳跃、合成键、定点起跑、伤害注入、headless与加速游戏时间均需看报告的方法字段；不能称为真人试玩。主美表现与独立操作检查、最终版本范围及局限在本版验收报告记录。
