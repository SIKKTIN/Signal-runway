## 信号崩塌

实际判定边界仍为控制器的front_x；不改变270单位/秒、640单位初始距离、2秒缓冲及角色运动。表现沿用 `bind_flow(flow,chase)` 和公开事件。

珊瑚色主波沿竖向连续滚动，由两条不同频率正弦组合；主分量空间频率0.035、时间频率4.2，波峰向下移动约120单位/秒。主波中心位于前沿后方13至63单位；12单位宽淡光晕、2.5单位主线以及更后方的青色回波均留在前沿后方。亮度保持平缓，移动来自位置变化，不靠高频闪烁。

后方覆盖沿用低亮度故障底纹，加入44单位/秒下行起伏波带、118单位/秒逆向数据片及86单位/秒沿波形流动的小信号包。依据用户对首版预览的纠正，已移除1单位宽竖直边界线及平直红色填色外边；底纹、深色覆盖、红色波带和信号包都沿滚动波形裁切，波形本身成为可见前沿。front_x作为逻辑上界不另行绘制；主波和底纹均无前方残影，也不画假安全区域。

所有动效只使用 `_animation_time`，不使用shader TIME。既有暂停、结果与声音逻辑保留；bind_flow重绑时清零时钟，世界重建清零。所有旧presentation_state字段保持，新增：

| 字段 | 含义 |
| --- | --- |
| coverage_max_x | front_x，所有致命覆盖不可越过的保守上界；不绘制竖直标记 |
| wave_center_offset_min/max | 13 / 63，主波中心相对front_x的后移范围 |
| wave_stroke_max_x | front_x-7，12单位光晕外缘的保守上界；抗锯齿仍有余量 |
| wave_travel_speed | 120，主分量竖向滚动速度 |

## 环境组件接入

制作人已在RunFlow的World中创建EnvironmentVisual、设置identity transform与z_index=-10，并调用 `bind_flow(flow: Node,camera: Camera2D,course: Node2D)`；随后设置Course.dynamic_environment_enabled=true，关闭Course旧背景绘制。地形、平台、尖刺、教学文字、终点与碰撞继续由Course原代码负责。

组件可在加入场景前绑定；ready后读取流程的phase和暂停状态。监听pause_changed、run_failed、run_finished、mode_changed，重绑/退出断开订阅，不积累监听。process_mode=ALWAYS使组件能读取结果状态，自有时钟在暂停或结果时停止，不靠Node自动处理时间。菜单和ready保留环境运动；原计时与测试房也有环境，不显示追赶覆盖。

环境层：

| 内容 | 动效与层级 |
| --- | --- |
| 远层厂区 | 0.14视差，低亮度建筑、稀疏窗灯，52单位/秒远方信号扫过横轨 |
| 中层机械面板 | 0.32视差，连续低频灯光呼吸，有限半径的柔和亮圈 |
| 近层线路 | 0.57视差，66单位/秒沿线路移动的信号短段、端点灯脉冲 |
| 微粒 | 确定性22个稀疏短线，只在y126–388背景带流动，不占主要地面/落点区域 |
| 终点信标 | Course.finish_x附近的金色柔光与向上移动的箭头；实际终点门与文字保持原绘制 |

视差从真实canvas逆变换的可见世界窗口计算，随着镜头平移分层运动，不受摄像机平滑滞后误差影响。没有音效节点、碰撞体、随机数依赖、业务输入或状态判定。无需新增位图、导入配置、第三方资源或Shader。

EnvironmentVisual.presentation_state提供animation_time、paused、resolved、phase、parallax_factors、camera_bound、course_bound。绑定或重建时clock=0；失败和成功冻结，原模式恢复时继续。
