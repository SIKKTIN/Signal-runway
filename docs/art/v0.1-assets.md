## 表现接口与 UI 皮肤

- `scripts/visual/player_visual.gd`：作为玩家节点的 `Node2D` 子节点挂载；在 `_ready` 中自行订阅父节点 `state_changed(state)` 和 `action_triggered(action)`，读取父节点 `facing` 并关闭已有 `fallback_visual_enabled` 占位绘制。它不写入速度、碰撞、死亡或统计。
- 内建的五个 `AudioStreamPlayer` 分别加载下表音效；如果工程存在 `SFX` 总线便使用它，否则用默认总线。流程完成时由制作人调用 `PlayerVisual.play_finish()`。
- `scenes/ui/skins/signal_theme.tres`：`Theme` 资源，覆盖 Label 与 Button 字色、字号及按钮 normal/hover/pressed/focus/disabled 样式，也提供 Panel 样式。开始、HUD、暂停和结算业务界面由制作人继承主题，按钮业务逻辑仍归制作人维护。
- `scenes/visual/art_preview.tscn`：独立视听预览。按 1–5 触发 jump、wall_jump、land、death、finish；左右键切换角色朝向。不包含物理关卡逻辑。

## 音频资源

| 路径（相对于 `res://`） | 格式 / 时长 | 对应公开动作 |
| --- | --- | --- |
| `assets/audio/sfx_jump.wav` | 48kHz、16-bit、mono / 0.180s | `jump` |
| `assets/audio/sfx_wall_jump.wav` | 同上 / 0.220s | `wall_jump` |
| `assets/audio/sfx_land.wav` | 同上 / 0.130s | `land`；只在一次落地事件触发 |
| `assets/audio/sfx_death.wav` | 同上 / 0.300s | `death` |
| `assets/audio/sfx_finish.wav` | 同上 / 0.620s | `play_finish()` |

WAV 导入为 `AudioStreamWAV`，`edit/loop_mode=0`；各事件重触发时先停止旧实例，避免同一事件堆叠。完整流程音量和听感在主干集成后再复核。

## 证据与边界

Godot 独立预览真实图形捕获见 `reports/v0.1/art/preview.png` 和 `preview_motion.png`，运动帧的灰度和 50% 缩小检查分别见同目录的 `preview_grayscale.png`、`preview_half.png`。五类音效已通过 Godot 图形进程加载与播放状态检查，记录见 `reports/v0.1/art/check.md` 和 `audio_metrics.json`。此任务验证资源与独立预览；首关完整接入和运动中的识别由制作人集成后联合检查。
