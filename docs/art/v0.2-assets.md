# 信号崩塌 v0.2 资源与接入清单

主美 C 任务：`d50eea61-70ac-4578-bde9-09a13a65861f`。沿用信号跑道的青色玩家、浅色安全顶边、珊瑚危险和金色终点。以下交付只消费公开事件；速度和警告阈值由制作人的控制器决定，表现不写死追赶速度。

## 正式表现接口

`res://scripts/visual/chase_visual.gd` 继承 `Node2D`，挂在 `World` 下，保持位置、旋转、缩放为单位变换。加入场景后调用 `bind_flow(flow: Node, chase: Node)`；也支持加入场景前绑定。绑定立即读取 flow 的 `mode`、`phase`、树暂停状态，以及 chase 的 `front_x`、`gap_px`、`warning_level`、`grace_remaining`，不等待下一次事件。

| 公共事件 | 表现处理 |
| --- | --- |
| `threat_updated(front_x, gap_px, warning_level, grace_remaining)` | 前沿严格对齐 `front_x`；更新距离和 grace/safe/near/urgent/stopped。重复同级事件不重播提示、不重启循环 |
| `mode_changed(time_trial/pursuit)` | 计时模式隐藏追赶层并停止声音；追赶模式同步当前控制器状态 |
| `pause_changed(paused)` | 冻结表现动画时钟和循环播放；停止短提示；继续时恢复同一循环，无额外警告提示 |
| `run_failed(reason, elapsed, furthest_ratio)` | 停止威胁循环、隐藏距离 HUD；caught 播放一次吞没声。spike/fall 沿用已有玩家死亡声 |
| `run_finished(elapsed, deaths, best)` | 停止所有追赶声音、隐藏距离 HUD，原有完成声仍由玩家表现处理 |
| 退出 / 重新绑定 | 断开旧事件，停止播放器并释放流；重新绑定只有一个 threat_updated 订阅 |

覆盖只画在前沿后方，前沿贴图的最右边就是判定边界。通过逆画布变换裁切可见区域，适配跟随镜头；结果状态保留已吞没区域，菜单隐藏。没有粒子或全屏闪烁，没有前沿前方的雾或亮面假地形。

追赶 HUD 为独立 `CanvasLayer`，逻辑坐标右上 `x=690..936、y=142..212`，避开主 HUD 与 y112 notice。安全使用勾形、接近使用双竖条、紧急使用三角叹号，并显示等级文字和“原地余量约 x.x 秒”。数值取 `max(gap_px,0)/max(chase.speed,1)`，只估算原地不动时的余量，前進/回退会改变它，不承诺精确死亡倒计时。启动缓冲显示真实 `grace_remaining`，公开原始属性保持不变。

## 声音与触发

全部音源为 48kHz、16-bit、mono WAV，Godot 导入 AudioStreamWAV。

| 路径（`res://assets/audio/v02/`） | 时长 / 源峰值 | 触发方式 |
| --- | --- | --- |
| `threat_loop.wav` | 2.00s / -12dBFS | 一个 ThreatLoop 播放器，复制资源设置完整两秒循环；safe/near/urgent 平滑到 -23/-17/-12dB 播放器音量 |
| `warning_near.wav` | 0.20s / -7dBFS | 等级进入 near 时一次播放，提示播放器 -7dB |
| `warning_urgent.wav` | 0.24s / -7dBFS | 等级进入 urgent 时一次播放，共用同一个提示播放器 |
| `caught.wav` | 0.46s / -4dBFS | caught 失败结果一次播放，播放器 -4dB；重复结果事件被忽略 |

ThreatLoop、WarningCue、CaughtCue 共三个播放器；优先用已存在的 SFX 总线。循环是整数周期低频波形，循环接缝的采样差不高于波形正常相邻采样差。启动缓冲、菜单、计时模式静音，暂停冻结循环，成功/失败停止循环，退出停止并释放所有流。

## 运行证据与边界

独立入口 `res://scenes/visual/chase_preview.tscn`；1–4 选择缓冲/安全/接近/紧急，5 显示三种失败皮肤，6 演示吞没，7 切换计时模式，P 冻结/恢复。

Godot 4.7.2 的 Windows D3D12 / RTX4050 图形进程生成 grace/safe/near/urgent/failure_skins/caught 六张截图。13 项声音与事件生命周期检查全部通过：初态同步、重复等级、暂停恢复、切换模式、结果唯一触发、重开、绑定去重、退出清理。前沿 x540 对应截图 x720，受覆盖影响的最右像素是719；前方角色与落点区域逐像素不变。灰度和 50% 缩小图已查看，边界和危险仍可辨。

结果见 `reports/v0.2/art/check.md`、`lifecycle-results.json`、`frame-check.json`。实际音频资源加载与播放状态有证据；本工具无法提供人的主观听感，未宣称完成舒适度或紧张感评价。正式关卡接入效果由 D 集成及 E 固定版本独立检查确认。
