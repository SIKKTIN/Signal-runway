## 视觉方向

沿用深蓝工业场景、青色角色与生命、白色真实落脚顶沿、金色收益、珊瑚色危险。冲刺使用短双箭头与青蓝尾迹，储备使用两格，充能使用两节点进度；每类信息同时有形状或文字。危险前沿保持波形，不恢复旧直线。

角色、白顶和真实落点优先于装饰。尾迹不画无敌光罩、不用亮线连接空隙、不预测落点来暗示自动救场。独立 DashVisual 绘制在角色后方，既有 PlayerVisual 继续负责跑跳、落地与终局，避免重复动画和音效。

| 状态 | 表现候选 | 业务依据 |
| --- | --- | --- |
| 起手 | 身后短双箭头与一次轻亮脉冲 | 实际开始事件，首次绑定快照不补播 |
| 冲刺中 | 最多四个低透明残影，沿已发生的位置衰减 | 实际角色位置与 dash_active |
| 正常结束 | 停止采样，尾迹短淡出 | 实际结束事件 |
| 受伤取消 | 结束采样，服从原受伤反馈 | 实际取消事件，不返还次数、不重复受伤音 |
| 充能中 | 两节点进度逐格变化 | 唯一节点结算后的实际资源快照 |
| 补充一次 | 新增储备格短闪，可选短音 | 次数确实增加的事件，转发去重 |
| 储备已满 | 两格常亮并写“已满” | 当前次数为 2，原节点计分照常 |
| 无次数尝试 | 短提示“冲刺耗尽”并轻闪一次 | 真实拒绝输入事件，不每帧重复提示 |

残影候选寿命约 0.12–0.18 秒，透明度和采样间隔待实际两尺寸画面调整。暂停时采样、衰减、闪烁与提示寿命冻结；终局、菜单、重试清理短反馈。表现不能改玩法参数。

## 资源 HUD 与布局

同时写清“冲刺 1/2”和“充能 1/2 节点”，两格分别表示可用次数，充能是独立信息。满储备写“已满”；没有次数仍显示充能途径，不开局补播获得次数提示。

优先尝试顶部统计下、左侧紧凑状态条，避开底部生命/路线状态、右侧追赶和节点面板、工具返回说明。逻辑画布候选为 `(24,138)`、宽约 250、高约 50；此位置尚未验证，三原型高路若进入该区域则调整。不能重复 v0.7 的落点被 HUD 覆盖问题。

960×540 与 1280×720 检查字体截断、次数格、角色与实际顶沿。Shift 指令需制作人接入既有底部操作说明，主美不改未授权的 EndlessHUDVisual。HUD 按真实快照重置，不自行推断补充、恢复或新一局。

## 路线入口和收益

技能标识绑定真实入口与落点：短双箭头、“需冲刺 ×1/×2”、真实节点收益。不足时显示“冲刺不足”和稳定主路方向；储备只改变提示，不改变生成地形。

捷径表达花费与高路收益，空中接力表达下一实际节点和落点，脱险表达操作机会。救场提示不能承诺成功，终局不提示可救回。原三节点序号、实际加分、延迟与站点互斥信息继续读取业务事件；充能音与原节点音同时触发时合并或降低新音量。

不重复绘制白色平台边界，不让标识遮挡起跳点、下一落点、角色和既有 HUD。路线延续不冒充完成奖励。位置随真实世界坐标、镜头与重定位同步；旧生成版本不显示新技能信息。

## A/B 放行接口需求

以下是接线需求，字段与签名以放行文档为准，不宣称已实现。

| 来源 | 需要冻结的内容 | 用途 |
| --- | --- | --- |
| Player | dash_enabled、dash_charges、dash_progress、dash_remaining、dash_active 的类型与单位 | 绑定快照、持续状态 |
| Player/RunFlow | dash_state_changed 签名；开始、结束、取消、耗尽、补充事件及去重 ID | 一次性反馈，防止转发重复 |
| 充能 | progress 是归一化值还是节点数；满储备、恢复、回跑和重定位语义 | 两节点进度与储备正确显示 |
| 生命周期 | 暂停、重试、菜单、终局顺序；旧版本 dash_enabled=false 行为 | 冻结、清理和旧入口兼容 |
| B 路线 | 固定入口/落点坐标、所需次数、唯一路线/原型 ID、节点收益、稳定替代路线与连接契约 | 实际需求和资源足够/不足提示 |

0.20 秒、800 单位/秒、约 160 单位位移只是 M1 原型初值。美术读取实际状态，不将初值写成最终手感或可达结论。唯一节点身份和资源预算由业务层维护。
