# 信号跑道：跑酷原型表现规格

美术方向：**高对比几何工业风**。参考 [方向板](signal-run-direction.svg)。GameCreator 的 `art-assets.style.draft` 是当前设计源；本文件记录 Godot 资源接入细节。原型首先验证快速移动时平台、尖刺和终点是否可辨。

## 方向比较

| 方向 | 优点 | 决定 |
| --- | --- | --- |
| A 信号跑道：平面几何、工业标识 | 安全顶边、三角尖刺和竖向终点靠轮廓区分 | 采用 |
| B 霓虹夜城：高光晕、密集灯牌 | 气氛强，但会争夺路线和危险物的注意力 | 仅保留少量速度感 |

## 画面层级

1. 玩家 `#45DCCB`：圆角前倾剪影，头部与脚部标明朝向。
2. 安全平台 `#E6EFED`：连续、水平、浅色顶边；实体用暗灰。
3. 危险 `#FF685C`：三角齿加斜纹基座，视觉朝向与实际碰撞一致。
4. 终点 `#FFD166`：竖向双框门加旗箭头，与尖刺形状明显不同。
5. 背景 `#18212B`、次级结构 `#334554`：不出现与可站立平台同亮度的水平边。

颜色仅为第二识别通道。按正常色与灰度、原尺寸与 50% 缩小画面分别检查剪影和边界；结果以 Godot 实际运动预览记录。

## 动作、UI、音效

- 角色状态：待机、奔跑、起跳、上升、下落、贴墙下滑、蹬墙、落地、死亡、抵达终点。拉伸与压缩不改变碰撞体。
- 失败：短促闪白和低音提示，不能拖慢重新取得控制的时间；尖刺边界不得被粒子遮挡。
- UI：以 960×540 为参考画布，安全边距 24px；左上显示等宽计时和死亡数；结算显示用时、死亡数和重玩入口。
- 音效：跳跃上扬、蹬墙反弹、落地轻碰、死亡短促低音、完成双音。连续触发须避免刺耳堆叠；试听音量以实际构建调整。

## Godot 接入约定

- 文件放在任务约定的 `assets/visual`、`assets/audio`，预览场景放在 `scenes/visual` 或 `scenes/ui`；不改玩家控制与关卡共享逻辑。
- 命名使用 `player_<state>_<index>.png`、`terrain_<type>.png`、`hazard_spike_<direction>.png`、`goal_gate.png`、`ui_<purpose>.png`、`sfx_<event>.wav`。小写英文与下划线，状态名在资源清单中固定。
- 视觉资源先按 32px 模数规划，人物约 24×32、尖刺约 32×32、终点约 48×96 像素；这些是原型出图规格，接入前与制作人核对世界单位和碰撞尺寸，不用缩放贴图弥补接口误差。
- 透明 PNG 保留直边与足够透明留白；小图标和 UI 以目标分辨率检查采样。短音效优先 48kHz WAV。导入后记录 Godot 版本、资源路径、尺寸、采样设置、音量和触发事件。
- 原型不依赖动态灯光、全屏后处理或大规模常驻粒子。同屏瞬时粒子建议不超过 32 个；以实际帧率和可读性检查决定调整。

## M1 检查

方向板与 GameCreator 资源条目作为规格交付。制作人可在移动测试房核对危险、平台、终点的可读性与资源接口；当前文档不代表视觉资源已制作或 Godot 运行效果已验证。
