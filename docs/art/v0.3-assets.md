## 冻结接口与接线

`scripts/visual/relay_visual.gd` 放在World下，identity transform；`bind_flow(flow,course)`可在ready前后调用。读取 `course.relays` 数组，每项 `{id:String,position:Vector2,activated:bool}`，不创建或改变位置。事件：

| 来源 | 行为 |
| --- | --- |
| flow.relay_activated(id,added_delay,count) | 稳定ID首次事件才显示0.42秒脉冲、播放一次短声、显示1.1秒toast；已激活或未知ID不重复 |
| flow.relay_delay_changed(remaining) | 同步公开延迟；ChaseVisual显示第三行倒计时 |
| pause_changed | 自有clock和脉冲/toast停留，短声stream_paused冻结；继续后恢复 |
| run_failed/run_finished | 冻结clock，停止短声，清除toast和延迟提示；不接收结算后的接入 |
| mode_changed / bind_flow | 读取现有phase与节点；重绑清零clock/脉冲/诊断计数并断开旧订阅；初始已激活节点静默呈现 |

level_id只以制作人的level01/relay_station为有效关卡值，测试房看lab_mode；本组件不依赖lab字符串。计时模式added_delay=0，仍有节点接入与数量反馈，ChaseVisual不显示追赶HUD。没有额外按键。

ChaseVisual.bind_flow优先读chase.relay_remaining，再兼容flow.relay_delay_remaining getter；随后消费根转发的relay_delay_changed。延迟只停止控制器平移，不停止现有波形clock；真实暂停和结果才冻结。HUD第三行“中继延迟 x.x秒”独立于“原地余量”估算，未将收益当精确死亡倒计时。HUD右侧y142–236；RelayToast同右侧y244–281，计时模式toast用y142–179。均避开顶端统计条；原主干中继计数在左侧y140。

presentation_state新增诊断：RelayVisual提供animation_time、paused/resolved、node_states、activated_ids、sound_triggers、sound_playing/paused、toast_visible、delay_remaining；ChaseVisual保留全部旧字段，并增加relay_delay_remaining、relay_delay_visible。
