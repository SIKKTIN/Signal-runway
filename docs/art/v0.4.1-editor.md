## 视觉规则

低饱和深蓝底#18212B，面板#182B36，输入框#111F29，普通按钮#20313C。正文#E6EFED，次级说明#A8BBC4；青色#45DCCB表示当前选择/主要操作，金色#FFD166表示注意与键盘焦点，珊瑚色#FF685C表示无效输入或规则错误。

选中、警告与错误不能只靠颜色：选中面板用2px边框，警告/错误面板用4px左标线，同时放“已选中”“注意”“无效配置”等文字。地图中的平台/墙/尖刺/空隙/中继继续依赖轮廓、标签和符号；工具选择边框不伪装成可碰撞地形。结构检查文字区分“规则满足”与“动作可达/玩家体验”，不自动宣布后两项通过。

正文与输入框15px，按钮15px，表格/列表15px，辅助说明14px，分区标题18px。中英数字都使用Microsoft YaHei UI / Microsoft YaHei / Noto Sans CJK SC / Arial的SystemFont回退。正文不得继承游戏20px大按钮字体。只读值保持可选择复制；无效输入保留当前值及具体原因，不用低对比灰字掩盖失败。

## Theme 接入

顶层Control.theme加载独立Theme。标准Button/OptionButton/LineEdit/SpinBox/CheckBox/ItemList/Tree/PopupMenu/PanelContainer/RichTextLabel和滚动条使用统一尺寸、背景与字色；业务节点不应覆写回游戏默认Theme。

| theme_type_variation | 基类 | 用途 |
|---|---|---|
| ToolPrimary | Button | 重新生成/试玩等当前主要动作；同一区域只突出一个 |
| ToolSelected | PanelContainer | 已选片段详情或当前配置 |
| ToolWarning | PanelContainer | 合法但需注意的兜底/配置差异 |
| ToolError | PanelContainer | 校验失败/写入失败 |
| ToolTitle | Label | 18px分区标题 |
| ToolMuted | Label | 14px辅助说明 |
| ToolWarningText | Label | 金色警告文字 |
| ToolErrorText | Label | 珊瑚色错误文字 |

普通按钮不使用危险红；应用工程默认属于需确认的操作，使用普通按钮配明确确认文案，风险说明才用警告样式。focus为2px金色透明边框，与青色选中状态区分；hover使用较亮深蓝及青色边，pressed使用青底深字；disabled有独立低亮背景但文字仍可读。输入框选区为暗青底白字。

## 1280×720 与960×540布局约定

制作人维护布局行为。1280宽使用左300参数区、中心地图和详情区；缩至960时保持字号，参数/详情纵向滚动，压缩地图可视宽度并允许整体适配。不要单纯缩放整张1280画布而使15px文字变成11px。外边距12px，分区间距8–12px，输入/按钮建议最小高度32px。

顶部seed/段数/生成/随机种子按组布局；指纹短显示前12字符、完整值供复制或tooltip，小宽度分两行。底部保存/加载/恢复/试玩/应用按功能组换行或排列成两行，不让应用按钮超出窗口。长中文检查原因、候选排除原因和配置差异使用换行，完整详情可滚动；列表条目仍保留ID和状态。弹窗必须在当前窗口范围内，确认/取消和错误原因可读。
