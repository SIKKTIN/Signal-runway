# 信号跑道 v0.2 运行说明

使用 Godot 4.7.2 stable 导入 project.godot，按 F5 运行。主入口 scenes/main/main.tscn；默认按钮为追赶挑战，另可选择原计时挑战或控制测试房。本版交付源工程，不打包。

| 操作 | 按键 |
| --- | --- |
| 移动 | A/D 或左右箭头 |
| 跳跃、蹬墙 | Space/W/上箭头，短按低跳、长按高跳 |
| 新挑战 | R，包含暂停和结果界面 |
| 暂停、继续 | Esc 或暂停按钮 |
| 开始、结果后再玩 | Enter 或界面按钮 |
| 控制测试房 | F2 或开始界面按钮 |

## 追赶挑战

首次移动或跳跃启动计时，2秒起步缓冲后，信号崩塌从后方持续逼近。手动奔跑、跳跃和蹬墙保持前进；停顿和回退会消耗安全距离，流畅通过能拉开距离。崩塌边缘后的区域致命。

HUD以图标、文字和颜色显示安全、接近、紧急三档。“原地余量约x.x秒”估算站在当前位置不动时的余量；前进、回退和障碍会改变情况。启动前不推进，暂停冻结计时、缓冲、边界和威胁循环。

被崩塌吞没、撞上尖刺或坠入空隙都结束整轮，结果显示原因、用时和最远进度。R或再次挑战会重置角色、镜头、追赶、计时和警告，等待新的首次动作；不会把你重生到已经崩塌的起点。终点与失败同帧时失败优先。

## 原计时挑战

开始界面选择“计时挑战·原规则”。没有后方追赶；死亡自动回到起点并继续累计本轮时间与死亡数。R清零本轮，暂停不计时。控制测试房使用这套规则。

两种模式分别记录本次程序会话的最佳成功用时，只有通关会更新最佳。失败不能覆盖成功最佳，退出程序后不保留记录。局内模式固定，返回开始界面后可重新选择。

## 开发记录

现有四段首关与动作参数保留。最终追赶参数为270单位/秒、起点后方640单位、缓冲2秒；数值比较和两处2秒停顿轨迹见reports/v0.2/route-budget.md。画面、规则、集成和独立检查记录见reports/v0.2，资源清单见docs/art/v0.2-assets.md。

本机实际验证使用Windows、D3D12、Forward+、RTX4050 Laptop GPU、1280×720窗口与960×540逻辑画布、60Hz物理。自动通关证明规则与路线可达；主观紧张感和音效舒适度仍可由使用者体验反馈，未宣称覆盖其他平台或外部玩家研究。
